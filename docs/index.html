🏙️ Stream City

Low-poly city by district. Scroll/pinch to zoom, drag to pan, double-click/tap to reset. Each track is a building scaled to its streams; big playlists draw simplified for speed.

🧪 Demo mode (static). Runs in your browser with mock data: any valid playlist link builds the same sample city. Real Spotify counts need the Flask server app.

Try: playlist link · playlist URI · album (mock: playlists only)
