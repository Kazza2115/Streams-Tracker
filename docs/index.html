🌆 STREAM CITY

Isometric city — each track is a building (taller = more streams), each artist a citizen walking the streets. Move your mouse for a 3D tilt.

🧪 Demo mode (static). Runs in your browser with mock data: any valid playlist link builds the same sample city. Real Spotify counts need the Flask server app.

Try: playlist link · playlist URI · album (unsupported)
